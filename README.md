# DigiAdapt AdTech Intel (MCP server)

Remote MCP server from [DigiAdapt](https://digiadapt.net): daily AdTech news on DSPs, SSPs, CTV and TV OEMs, with a searchable archive, a market-signal view and DigiAdapt's advisory profile.

- **Endpoint (streamable HTTP):** `https://digiadapt.net/mcp`
- **Registry name:** `net.digiadapt/adtech-intel`
- **More:** https://digiadapt.net/adtech-intel

This repository holds the registry metadata (`server.json`) for the public MCP Registry listing. The server itself is hosted at the endpoint above.
